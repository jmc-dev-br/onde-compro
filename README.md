# Onde compro?

Buscador de produtos em português para encontrar caminhos relevantes para comprar itens comuns ou difíceis de achar.

O site é estático e pode ser hospedado no Cloudflare Pages. A busca abre pesquisas em mecanismos amplos e marketplaces conhecidos; ela não afirma que encontrou o produto mais barato nem o anúncio mais popular sem dados de comparação reais.

## Executar localmente
Abra `index.html` em um navegador.
