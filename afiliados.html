Quais lojas podem ser automatizadas?

Amazon

Automática quando você salva sua tag de associado como segredo AMAZON_ASSOCIATES_TAG no Cloudflare. Este cadastro manual é opcional.

Shopee

Automática quando o programa fornecer credenciais da Open API e você salvar SHOPEE_AFFILIATE_APP_ID e SHOPEE_AFFILIATE_APP_SECRET como secrets no Cloudflare.

Mercado Livre, Temu e TikTok Shop

Use o gerador oficial de links do programa para cada produto. O TikTok Shop informa que seus links de afiliado externos são gerados pelo aplicativo; o Mercado Livre também pede que se use o gerador/barra oficial.

Awin, Impact e outros

Se a rede gerar um deep link oficial, cadastre aqui. Uma integração automática por API exige aprovação, credenciais e compatibilidade do programa da loja.
